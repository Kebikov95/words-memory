# WordsMemory — тренажёр иностранных слов

Личный словарь-тренажёр: итальянский и английский → русский.
Чистый HTML/CSS/JS — без фреймворков, сборки и бэкенда. Данные хранятся
в браузере (localStorage), каждый профиль изолирован.

## Запуск

Открыть `index.html` в браузере — этого достаточно. Для аккуратности можно
поднять локальный сервер:

```bash
python3 -m http.server 8080
# → http://localhost:8080
```

## Возможности

- **Профили** — несколько пользователей, у каждого свой словарь (опциональный PIN)
- **Готовые наборы (страница «Группы»)** — для итальянского и английского:
  топ-100 глаголов, топ-100/1000/3000 частотных слов (ядро), еда, одежда,
  части тела, фразовые глаголы (en), пословицы, бизнес, ИТ, путешествия,
  финансы, прилагательные, цвета, цифры, спорт. Добавление в словарь
  выбранных или всех слов одним кликом, тег набора проставляется автоматически.
  Слова в наборах правятся карандашом как в словаре — слово, транскрипция,
  перевод, примеры (🇮🇹/🇬🇧), теги, своя картинка. Правки готовых наборов
  сохраняются в браузере как персональные и применяются при каждом открытии
- **Свои наборы** — кнопка «+ Создать набор» на странице «Группы»: название,
  язык, тег и список слов в формате `слово | перевод | пример | перевод примера`.
  Наборы хранятся в браузере вместе со словарём профиля, открываются
  по клику на карточку (работает кнопка «назад» браузера)
- **Две вкладки** — Italiano / English, перевод всегда на русский
- **Слова** — перевод, несколько примеров с переводами, теги, картинка
  (подбирается автоматически через Википедию, можно заменить своей)
- **Озвучка** — встроенный в браузер синтез речи (Web Speech API), бесплатно
- **Фильтр по тегам + поиск** по слову, переводу и примерам
- **Импорт/экспорт JSON**, массовое добавление списком
  (`слово | перевод | пример | перевод примера`)
- **5 режимов тренировки** (5/10/15/30/50 слов):
  собери слово, диктант, слово↔перевод, картинка↔перевод, микс
- **Статистика** тренировок и повтор ошибок по итогам
- Современный минималистичный интерфейс, тёмная тема (авто + переключатель)
