# AGENTS.md — js/

Вся логика приложения. Никакой модульной системы и сборки: каждый файл —
один модуль, который вешает себя на глобальный объект `window.WM`
(исключения — `icons.js`, создающий `window.ICONS`). Данные готовых
наборов лежат в `data/*.json` и грузятся fetch'ем (см. `groups-data.js`).
Порядок подключения задан в `index.html` и нарушать его нельзя: файлы ниже
используют то, что определено выше. Точка входа — `WM.app.init()` в
конце `app.js`.

## Файлы (в порядке загрузки)

### icons.js → `window.ICONS`
Набор инлайн SVG-иконок в стиле Lucide (speaker, pencil, trash, plus, play,
download, upload, x, sun, moon, chart, user, lock, settings). Иконки —
готовые HTML-строки, вставляются через `innerHTML`, работают офлайн.

### storage.js → `WM.storage`
Единственный слой доступа к данным (localStorage, изоляция по профилю).
- Профили: `getUsers`, `createUser` (уникальность имени; PIN сразу хешируется
  SHA-256 через `crypto.subtle`), `verifyPin`; текущий пользователь:
  `currentUserId`, `setCurrentUser`, `clearCurrentUser`.
- Слова: `getWords`/`setWords`, `addWord` (проставляет `id`, `createdAt`,
  значения по умолчанию), `updateWord`, `patchWordField`, `deleteWord`,
  `importWords` — массовый импорт с нормализацией полей (включая
  `transcription`), защитой от дублей (ключ `lang|word|translation`) и
  генерацией новых id.
- Статистика: `getStats`, `addStats` (хранит последние 100 тренировок).
- Ключи: `wm_users`, `wm_current`, `wm_words_<uid>`, `wm_stats_<uid>`.

### tts.js → `WM.tts`
Озвучка через Web Speech API (бесплатно, без ключей). Настроек голоса нет —
голос выбирается автоматически.
- `init` — загрузка и обновление списка системных голосов.
- Подбор голоса: `pickVoice` — отбрасывает роботизированные/«шутливые»
  голоса macOS (регекс `BAD`), в Chromium-браузерах предпочитает удалённые
  голоса Google (встроенные «compact»-голоса macOS там играются с глухим
  тембром и ускоренным темпом), иначе рейтингует по региону
  `it-IT`/`en-US`, качеству (enhanced/premium) и локальности;
  `currentVoice` — имя для статистики.
- `speak(text, lang)` — одна фраза с дефолтной скоростью; после `cancel()`
  выдерживается пауза ~60ms, иначе движок стартует фразу с искажениями.
- `speakSequence(items)` — слово + примеры строго по очереди: следующая
  фраза запускается только по `onend` предыдущей (общая очередь в Chromium
  ускоряется); токен `chainToken` прерывает цепочку при новом запросе.
  `supported()` — проверка поддержки.

### images.js → `WM.images`
Картинки слов: автоподбор из Википедии + эмодзи-фолбэк.
- `fetchImage(word, lang)` — поиск первой thumbnail-картинки статьи через
  открытый API `it/en.wikipedia.org` (таймаут 6с, без ключа).
- `emojiForWord(word, tags)` — эмодзи по тегу/слову, иначе 📘.
- `renderPreview(image, word, tags, cls)` — HTML превью для карточки:
  base64 → url (с `onerror`-фолбэком) → эмодзи.
- `imageToBase64(file, maxSize=400)` — сжатие пользовательской картинки
  в JPEG data-URL через canvas.

### io.js → `WM.io`
Импорт/экспорт словаря в JSON.
- `exportJSON(user, words)` — собирает payload формата
  `{app, version, exportedAt, user, words}` и скачивает файл через Blob.
- `importJSON(file, uid)` — парсит файл (массив или `{words: [...]}`) и
  передаёт в `WM.storage.importWords`; возвращает `{added, skipped}`.

### data/*.json — данные готовых наборов (без модуля)
Один JSON-файл на группу слов; зеркало it/en живёт в одном файле.
- `_meta`: `{id, name, icon, tag, desc, size?, "id-en"?, "name-en"?, "tag-en"?, "desc-en"?, "size-en"?}` —
  у en-«одиночек» (phrasal, irregular-verbs-en) `id` и `name` заданы напрямую.
- Записи — по русскому слову-ключу: `{ "en": {word, transcription, examples},
  "it": {…}, "img": "…" }`; блок языка может отсутствовать (слово только
  в одном языке). `examples` — массив `{text, translation}` (или строка);
  `img` — '' / url / эмодзи, общий для обоих языков.
- Повторный русский перевод в файле получает ключ с суффиксом « ·2»
  (снимается `stripMarker` при показе). Пополнить картинки —
  `node tools/fetch-images.mjs`.

### groups-data.js → `WM.groupsData`
Асинхронный загрузчик каталога: fetch'ет все файлы из `FILES` (порядок = порядок
каталога, внутри файла сначала it-, затем en-группа), нормализует записи и
складывает группы в `GROUPS`. Экспортирует:
- `ready` — промис загрузки (никогда не реджектится; статус в `state`:
  `loading/ok/error`); код с `GROUPS` обязан его дождаться;
- `GROUPS` (массив `{id, name, icon, lang, tag, desc?, size?, words}`, слово:
  `{word, transcription, translation, examples, image, src}`), `get(id)`;
- `files`/`originals` — распарсенные и исходные JSON (редактор картинок);
- `imgOf(src)`, `setImage(src, image)` — чтение/правка `img` записи
  (`src` = `{file, key}` из `word.src`);
- `changedFiles()` — изменённые файлы `[{file, json}]` для экспорта редактора.

### words.js → `WM.words`
Страница «Словарь»: список, добавление/редактирование, поиск, теги.
- `filtered()`, `allTags()` — фильтрация по языку/тегу/поиску (поиск идёт
  по слову, переводу и примерам).
- `render()` + `cardHTML()` — сетка карточек; транскрипция выводится рядом
  с кнопкой озвучки слова (кнопка произносит только слово), перевод —
  отдельной строкой под словом; пример на карточке — только на языке слова
  (парный пример-перевод остаётся в данных и виден в модалке редактирования):
  текст примера и его перевод на отдельных строках, динамик в конце строки
  примера, озвучка по `e.lang`; обработчики действий карточек
  (редактировать, удалить, озвучить слово, клик по тегу).
- Модалка слова: `openWordModal`, `addExampleRow` (каждая строка хранит
  свой `dataset.lang` и флажок), `saveWord` — после сохранения в фоне
  (`WM.images.fetchImage`) тихо подтягивает картинку.
- Массовое добавление: `parseBulkLine` (формат
  `слово | перевод [| пример | перевод примера]`, разделитель `|` или ` - `)
  и `saveBulk`.
- `init()` — подписки на тулбар, поиск, загрузку своей картинки,
  добавляет в тулбар кнопку «Добавить списком».

### games.js → `WM.games`
Тренировки: 5 режимов и результаты.
- Режимы (`MODES`): `assemble` (собери слово из букв), `dictation`
  (диктант по озвучке), `match-word` (слово↔перевод), `match-image`
  (картинка↔перевод), `mix` (вперемешку, включает quiz «выбери перевод»).
- `openSetup(words?, lang?, label?)` — модалка настройки; может принять
  предопределённый пул слов (тренировка из набора на странице «Группы»).
- `start()` — перемешивает пул, режет до выбранного количества и создаёт
  `session` (задания, счётчики, ошибки, таймеры).
- Отрисовка заданий: `renderAssemble`, `renderDictation`, `renderQuiz`
  (только в «Миксе»), `renderMatch` (общая для обоих режимов сопоставления,
  пары набираются из подряд идущих заданий одного типа). Сравнение ответов —
  через `norm()` (регистр, диакритика, пробелы).
- `finish()` — сохраняет результат в `WM.storage.addStats`, показывает экран
  результатов со списком ошибок; `exit()` — выход из тренировки.
- `init()` — кнопка «Тренировка», старт, выход, «Пройти ещё раз».

### groups.js → `WM.groups`
Страница «Группы»: каталог готовых наборов из `WM.groupsData`.
- `render()` — каталог с фильтром по языку и названию (дождавшись
  `WM.groupsData.ready`; при ошибке загрузки — подсказка про http-сервер);
  `renderDetail()` — просмотр набора: поиск внутри набора, чекбоксы, пометка
  «✓ в словаре» (сравнение по нормализованному ключу через
  `existingKeys`/`norm`).
- Картинки в строках набора (`loadGroupImages`): квадрат 40×40 между
  чекбоксом и словом; источник — кеш в localStorage (`wm_group_images`,
  общий для профилей; url-выбор редактора и пометка «нет») → картинка слова
  из словаря → `img` записи из data/*.json → Википедия
  (`WM.images.fetchImage`, 3 параллельных запроса). Слова с `img` в данных
  или кешем не запрашиваются вовсе. «Не найдено» держится только в памяти
  сессии и не кешируется.
- `addWords()` — добавляет выбранные/все слова в словарь
  (`WM.storage.importWords`, тег набора и картинка из данных проставляются
  автоматически) и в фоне подбирает картинки для первых 8 новых слов
  без картинки.
- Тренировка набора: «Тренировать выбранные»/«Тренировать набор» передают
  пул в `WM.games.openSetup`.

### editor.js → `WM.editor`
Редактор картинок (страница «images», открывается из меню аватара).
- Блоки = файлы `data/*.json` (`buildStructure`): файлы со словами обоих
  языков — секция «Общие 🇮🇹🇬🇧» (картинка ставится обоим сразу), одиночные —
  под 🇬🇧 или 🇮🇹. Строки = записи JSON (`blockWords`): один русский ключ =
  одна строка со словами обоих языков.
- Источники картинки строки (`imageFor`): слово словаря → кеш групп
  (`wm_group_images`, включая пометку «нет») → `img` записи данных.
- `applyImage` — пишет выбор в слова словаря, кеш групп и `img` записи
  (`WM.groupsData.setImage`, base64 в JSON не пишется); «Другая»
  (`nextImage`) листает варианты Википедии с дозапросом через `gsroffset`.
- «Выгрузить изменения» (`exportChanged`) скачивает изменённые
  `data/*.json` (`WM.groupsData.changedFiles()`) — ими заменяют файлы в
  папке `data`, делая картинки постоянными.
- `render()` дожидается `WM.groupsData.ready`; при ошибке загрузки —
  подсказка про http-сервер.

### app.js → `WM.app`
Ядро приложения и точка входа (`WM.app.init()` вызывается в конце файла).
- Состояние: `WM.app.state = { uid, user, lang }` — текущий профиль и
  активная вкладка языка.
- Служебное: `WM.esc()` — экранирование HTML (обязательно для любых
  пользовательских данных в HTML-строках), `showView(name)` — переключение
  экранов (`auth`/`app`/`game`/`results`), `toast(msg, isErr)`,
  `confirm(text, okLabel)` — промис на модалке подтверждения.
- Тема: `applyTheme`/`toggleTheme` (ключ `wm_theme`, авто по системе).
- Вход: `renderAuth` (список профилей), `askPin`, `createProfile`,
  `enterApp` (инициализирует и связывает модули один раз), `logout`.
- Внутри приложения: `showPage` (Словарь/Группы), `setLang` (вкладки
  it/en), импорт/экспорт, `openStats` (модалка статистики), установка
  иконок и закрытие модалок.

## Соглашения

- Новые модули: создавать файл `имя.js`, вешать на `window.WM.имя`,
  подключать в `index.html` **до** модулей, которые его используют, и до
  `app.js`; в начале файла писать однострочный комментарий-аннотацию.
- Весь пользовательский текст в HTML-строках — только через `WM.esc()`.
- Прямых обращений к localStorage вне `storage.js`/настроек темы и голосов
  избегать; данные слов — только через `WM.storage`.
- При изменении любого файла повышать `?v=N` у его `<script>` в `index.html`.
