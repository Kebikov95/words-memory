# AGENTS.md — WordsMemory

Тренажёр иностранных слов: итальянский и английский → русский.
Чистый HTML/CSS/JS — **без фреймворков, сборки и бэкенда**. Все данные
хранятся в браузере (localStorage), каждый профиль изолирован.

## Структура проекта

| Путь | Назначение |
|---|---|
| `index.html` | Единственная страница приложения. Содержит все экраны (вход, словарь, игра, результаты) и все модальные окна (`<dialog>`), подключает CSS и JS |
| `css/` | Стили: дизайн-система, темы, все экраны и компоненты. См. `css/AGENTS.md` |
| `js/` | Вся логика приложения, один файл = один модуль. См. `js/AGENTS.md` |
| `data/` | Данные готовых наборов: один JSON-файл на группу слов. Ключ записи — русское слово, внутри блоки языков `en`/`it` (word, transcription, examples) и общая `img`. См. схему в заголовке `js/groups-data.js` |
| `tools/fetch-images.mjs` | Пакетная заливка `img` в `data/*.json` из Википедии: `node tools/fetch-images.mjs` |
| `README.md` | Описание возможностей и формата экспорта для пользователей |

## Архитектура

- Никакой модульной системы: каждый файл вешает один модуль на глобальный
  объект `window.WM` (`WM.app`, `WM.storage`, `WM.words`, `WM.games`,
  `WM.groups`, `WM.groupsData`, `WM.tts`, `WM.images`, `WM.io`,
  `WM.editor`) либо, как `icons.js`, определяет глобальный `window.ICONS`.
- Скрипты подключаются в `index.html` через `defer` **в строгом порядке
  зависимости** (см. порядок в `<head>`). Точка входа — `WM.app.init()` в
  конце `js/app.js`; она инициализирует все остальные модули.
- Данные наборов (`data/*.json`) грузятся **асинхронно fetch'ем** в
  `WM.groupsData` сразу при старте: код, читающий `WM.groupsData.GROUPS`,
  обязан дождаться `WM.groupsData.ready` (страницы «Группы» и редактор
  картинок делают это сами). Значит приложение работает только по http —
  открыть `index.html` как `file://` нельзя.
- Единственный источник состояния приложения — `WM.app.state`
  (`{ uid, user, lang }`). Остальные модули читают его через
  `WM.app.state`, а данные всегда берут из `WM.storage`.
- Рендер императивный: модули сами генерируют HTML-строки (обязательно
  через `WM.esc()` для пользовательских данных) и навешивают обработчики
  после `innerHTML`.
- Экраны переключает `WM.app.showView(name)` — имена: `auth`, `app`,
  `game`, `results` (элементы `#view-*`).

## Соглашения

- **Git — только с ведома пользователя**: никогда не делать коммиты,
  пуш, пуш --force, сбросы и другие изменяющие историю действия без
  явной просьбы или подтверждения пользователя. Изменения файлов
  в рабочем дереве это не ограничивает.
- **Кеш-бастинг**: при любом изменении js/css повышайте версию `?v=N` у
  соответствующих `<link>`/`<script>` в `index.html` (комментарий об этом
  есть в `<head>`).
- Ключи localStorage начинаются с `wm_`; слова пользователя —
  `wm_words_<uid>`, статистика — `wm_stats_<uid>`.
- PIN профиля хранится как SHA-256-хеш (`crypto.subtle`), не в открытом виде.
- Тема: `[data-theme="dark"|"light"]` на `<html>`, ключ `wm_theme`
  (пустое значение = следовать системной).
- Текст интерфейса и комментарии — на русском.
- Запуск: только через http — `python3 -m http.server 8080` или встроенный
  сервер IDE (fetch в `file://` браузеры блокируют, наборы не загрузятся).
